# ON3RT Radio Suite — dépendances d'exécution (pip)
#
# Liste établie par analyse statique (AST) de l'ensemble des fichiers
# Python suivis par Git dans ce dépôt — aucune dépendance devinée ou
# approximative. La bibliothèque standard Python et les modules
# internes du projet (apps/, core/, libraries/) ne figurent pas ici.
#
# Uniquement les dépendances nécessaires à l'exécution de la Suite —
# pytest (tests/) est une dépendance de développement, volontairement
# exclue d'ici.
#
# Versions minimales (>=) : celles effectivement installées et
# validées lors du développement de cette version de la Suite.

# --- Interface graphique --------------------------------------------
# Qt pour Python : fenêtre principale, tous les modules, tous les
# panneaux du Dashboard. Dépendance structurante de l'ensemble de
# l'application.
PySide6>=6.11.1

# --- Communication série (CAT) --------------------------------------
# Communication CAT/CI-V avec la radio (apps/cat_server,
# apps/radio_control, libraries/cat/serial_transport.py). Le paquet
# pip s'appelle "pyserial" ; le code l'importe sous le nom "serial".
pyserial>=3.5

# --- Réseau -----------------------------------------------------------
# Client QRZ.com XML (libraries/qrz/client.py), utilisé par le Logbook
# pour la recherche d'indicatifs.
requests>=2.32.5

# --- Fonctionnalité optionnelle ---------------------------------------
# Affichage CPU/RAM dans la barre d'état (libraries/ui/components/
# statusbar.py). Import protégé par un bloc try/except dans le code :
# la Suite démarre et fonctionne normalement si ce paquet est absent,
# seul cet indicateur reste alors masqué.
psutil>=7.2.2

# --- Audio (infrastructure Voix) --------------------------------------
# Sélection du périphérique de sortie et lecture WAV
# (libraries/audio/audio_output_service.py), première brique du
# service Voix partagé de la Suite. numpy est utilisé directement pour
# manipuler les échantillons audio (lecture WAV, ré-échantillonnage).
sounddevice>=0.5.5
numpy>=2.4.2

# --- Synthèse vocale (VoiceService) -------------------------------------
# Moteur de voix système (SAPI5) par défaut de VoiceService
# (libraries/voice/engines.py::Pyttsx3Engine) — toujours disponible en
# pratique sous Windows. pywin32 (module "pythoncom") est importé
# directement pour initialiser/libérer explicitement l'appartement COM
# autour de chaque synthèse, exécutée sur un thread du QThreadPool
# global (voir docstring d'engines.py).
pyttsx3>=2.99
pywin32>=312

# Second moteur de VoiceService, optionnel (libraries/voice/engines.py::
# PiperEngine — étape 4f) : voix neuronales de meilleure qualité,
# jamais utilisé par "auto" (params.engine=None reste pyttsx3), choisi
# explicitement via VoiceParams(engine="piper"). Depuis piper-tts>=1.3.0,
# espeak-ng et onnxruntime sont embarqués dans le wheel pip — aucune
# installation système séparée requise sous Windows. Les modèles de
# voix (.onnx + .onnx.json) ne sont PAS installés par pip : à déposer
# manuellement dans data/piper_voices/ (jamais téléchargés
# automatiquement par la Suite, voir docstring de PiperEngine).
piper-tts>=1.3.0
